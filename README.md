# Trekking Management Application

A web-based Trekking Management Application developed as part of the Modern Application Development I course project.

The application allows Admin, Trek Staff, and Trekkers to manage trekking activities based on their respective roles.

## Technologies Used

- Flask
- SQLite
- Jinja2
- HTML
- CSS

## Main Features

- Role-based login and registration
- Admin management of treks, staff, users, and bookings
- Trek staff approval and trek assignment
- Trek staff management of assigned treks and participants
- Trek booking and cancellation
- Prevention of duplicate bookings and overbooking
- Trek and booking status tracking
- User booking history and profile management
- Search and filtering functionality

## Running the Application

1. Make sure Python is installed on the system.

2. Install Flask using:

pip install flask

3. Open the project folder in the terminal.

4. Run the application using:

python app.py

5. Open the local address displayed in the terminal in a web browser.
